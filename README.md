# TeachLink - Class Management System

_A powerful and efficient Class Management System built with Flutter and MongoDB._

## 🚀 About TeachLink

TeachLink is a modern and intuitive **Class Management System (CMS)** designed to help educators and institutions streamline classroom operations, track student progress, manage schedules, and enhance communication.

## ✨ Features

- 📚 **Course & Class Management** – Organize and manage classes efficiently.
- 👨‍🎓 **Student & Teacher Profiles** – Secure and centralized user accounts.
- 📅 **Attendance Tracking** – Automated attendance records.
- 📝 **Assignment & Grade Management** – Track student performance easily.
- 🔔 **Notifications & Announcements** – Keep students and teachers updated.
- 🌐 **Cross-Platform Compatibility** – Available on Android, iOS, and Web.

## 🛠️ Tech Stack

- **Frontend:** Flutter (Dart)
- **Backend:** Flutter
- **Database:** MongoDB
- **Authentication:** Firebase
- **State Management:** Provider
- **Hosting:** Firebase
